# Useful searches after launch

| Search | Expected result (bundled data) |
|---|---|
| Year 1956 + Mickey Mantle | Separate #135 gray-back and white-back cards |
| Year 1956 + team Baltimore Orioles | Team-card layouts and other researched team records |
| Year 1983 + Rookie + Hall of Fame | Sandberg #83, Gwynn #482, Boggs #498 |
| Year 1980 + Rickey Henderson | #482 rookie card |
| Year 1948 | 19 K-series records |

The gallery's opening view is **not** intended to imply that unknown player names or missing scans have been authenticated. Refining with a known player is a good starting point for the current partial dataset.

# How future database improvements appear

Adding `images.frontUrl` to a card produces a thumbnail. Clicking it opens a large image. Adding `images.backUrl` enables the back tab in that same viewer. Adding `isRookie` or `isHallOfFame` booleans makes the card's badges definite and includes the item when the respective filter is on. Additional variant states become their own tiles automatically.
